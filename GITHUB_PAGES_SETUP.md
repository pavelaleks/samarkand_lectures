## 🔧 Что нужно проверить на GitHub

### 1. Включить GitHub Pages

1. Перейдите в репозиторий: `https://github.com/pavelaleks/samarkand_lectures`
2. Откройте **Settings** (Настройки)
3. В боковом меню найдите **Pages**
4. В разделе **Source** выберите:
   - **Source**: `GitHub Actions` (не Deploy from a branch!)
   - Это должно автоматически активироваться после первого запуска workflow

### 2. Проверить статус деплоя

1. Перейдите на вкладку **Actions** в репозитории
2. Проверьте, что workflow `Deploy to GitHub Pages` запустился после последнего push
3. Дождитесь завершения (обычно 2-5 минут)
4. Убедитесь, что статус — зеленый (✅)

### 3. Проверить сайт

После успешного деплоя сайт будет доступен по адресу:
```
https://pavelaleks.github.io/samarkand_lectures/
```

⚠️ **Важно**: После первого деплоя может потребоваться 1-5 минут для активации GitHub Pages.

## 📝 Что происходит автоматически

- При каждом push в ветку `main`:
  1. Запускается GitHub Actions workflow
  2. Устанавливаются зависимости (`npm ci`)
  3. Выполняется сборка (`npm run build`)
  4. Файлы из `src/data` копируются в `dist/src/data`
  5. Собранный сайт деплоится на GitHub Pages

## ⚠️ Возможные проблемы

### Сайт показывает 404
- Проверьте, что GitHub Pages использует **GitHub Actions** как источник
- Проверьте, что workflow успешно выполнился
- Подождите несколько минут после первого деплоя

### Файлы лекций не загружаются
- Убедитесь, что файлы находятся в `src/data/[course]/лекции/`
- Проверьте, что файлы закоммичены в Git
- Проверьте консоль браузера (F12) на наличие ошибок 404

### Путь к файлам неправильный
- Убедитесь, что в `vite.config.js` установлен `base: '/samarkand_lectures/'`
- Проверьте, что все пути начинаются с `/samarkand_lectures/` или `/src/data/`

## 📞 Если что-то не работает

1. Проверьте вкладку **Actions** на GitHub — есть ли ошибки?
2. Проверьте вкладку **Settings → Pages** — правильно ли настроен источник?
3. Посмотрите логи workflow в GitHub Actions
4. Проверьте консоль браузера на сайте (F12)
