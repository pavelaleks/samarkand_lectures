# Как добавить лекции

## 📋 Структура файлов

### 1. Создайте JSON файл для лекции

Для каждой лекции создайте файл в папке `src/data/[курс]/лекции/`

**Пример:** `src/data/alternative/лекции/1.json`

```json
{
  "number": "1",
  "title": "Альтернативная литература как понятие: «вне канона», «контркультура», «нон-мейнстрим».",
  "gammaUrl": "https://gamma.app/embed/iti4sjrsnaqw48i",
  "id": "alternative-1"
}
```

**Поля:**
- `number` - номер лекции (строка, например "1", "10")
- `title` - заголовок лекции
- `gammaUrl` - URL для встраивания Gamma презентации (формат: `https://gamma.app/embed/...`)
- `id` - уникальный идентификатор (опционально, будет создан автоматически)

### 2. Добавьте PDF материалы (опционально)

1. Поместите PDF файлы в `src/data/[курс]/материалы/`
2. Назовите файлы с номером лекции в начале:
   - `1_Название статьи.pdf`
   - `1_Дополнительный материал.pdf`
   - `10_Статья по теме.pdf`

### 3. Обновите индекс

После добавления файлов запустите:

```bash
npm run process-lectures
```

Скрипт автоматически:
- Найдет все JSON файлы лекций
- Свяжет PDF материалы по номерам
- Обновит `src/data/lectures.json`

## 📚 Примеры

### Пример 1: Лекция с Gamma презентацией

**Файл:** `src/data/alternative/лекции/1.json`
```json
{
  "number": "1",
  "title": "Альтернативная литература как понятие",
  "gammaUrl": "https://gamma.app/embed/iti4sjrsnaqw48i"
}
```

### Пример 2: Лекция с материалами

**Файл:** `src/data/alternative/лекции/1.json`
```json
{
  "number": "1",
  "title": "Альтернативная литература как понятие",
  "gammaUrl": "https://gamma.app/embed/iti4sjrsnaqw48i"
}
```

**PDF файлы в папке `src/data/alternative/материалы/`:**
- `1_Ключевые концепции.pdf`
- `1_Примеры текстов.pdf`

После запуска `npm run process-lectures` материалы автоматически свяжутся с лекцией.

## ✅ Проверка

После добавления лекций:
1. Запустите `npm run dev`
2. Откройте страницу курса
3. Проверьте, что лекция отображается
4. Раскройте лекцию - должна появиться Gamma презентация
5. Проверьте PDF материалы (если добавили)
