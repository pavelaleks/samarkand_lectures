# Инструкция по добавлению лекций

## Структура папок

Для каждого курса (alternative, imagology, modern-literature) созданы три папки:

1. **лекции/** - для исходных файлов лекций
2. **презентации/** - для PDF презентаций  
3. **материалы/** - для дополнительных PDF материалов

## Как добавить лекцию

### Шаг 1: Подготовка файлов

1. **Лекция** (Word файл):
   - Создайте или откройте ваш файл лекции в Word
   - Сохраните как `.docx`
   - Назовите файл по номеру лекции: `1.docx`, `2.docx`, `3.docx` и т.д.
   - Поместите в папку `src/data/[название-курса]/лекции/`

2. **Презентация** (если есть):
   - Сохраните презентацию как PDF
   - Назовите файл тем же номером: `1.pdf`, `2.pdf`, `3.pdf` и т.д.
   - Поместите в папку `src/data/[название-курса]/презентации/`

3. **Материалы** (если есть):
   - Сохраните материалы как PDF
   - Название файла должно начинаться с номера лекции: `1 - Название.pdf`
   - Или просто: `1 Название материала.pdf`
   - Название после номера будет использовано для отображения
   - Поместите в папку `src/data/[название-курса]/материалы/`

### Шаг 2: Обновление индекса

После добавления файлов запустите:

```bash
npm run process-lectures
```

Этот скрипт:
- Найдет все новые файлы лекций
- Создаст записи в `src/data/lectures.json`
- Свяжет презентации и материалы с соответствующими лекциями

### Шаг 3: Генерация аннотаций

1. Откройте админ-панель: `http://localhost:5173/admin`
2. Убедитесь, что API ключ DeepSeek настроен
3. Выберите лекции для обработки (галочками)
4. Нажмите "Сгенерировать аннотации"

Система автоматически:
- Извлечет текст из .docx файлов
- Отправит его в DeepSeek API
- Создаст развернутые аннотации
- Сохранит результаты

## Примеры

### Структура для курса "Альтернативная литература":

```
src/data/alternative/
├── лекции/
│   ├── 1.docx  (Лекция о каноне)
│   ├── 2.docx  (Лекция о контркультуре)
│   └── 3.docx
├── презентации/
│   ├── 1.pdf
│   ├── 2.pdf
│   └── 3.pdf
└── материалы/
    ├── 1 - Статья о Бахтине.pdf
    ├── 1 - Материал о каноне.pdf
    └── 2 - Книга о контркультуре.pdf
```

### Нумерация

Важно соблюдать нумерацию:
- Лекции: `1.docx`, `2.docx`, `3.docx`...
- Презентации: `1.pdf`, `2.pdf`, `3.pdf`...
- Материалы: `1 Название.pdf`, `2 Название.pdf`...

Номер в начале названия файла материала определяет, к какой лекции он относится.

## Отображение на сайте

После обработки:
- Лекции появятся на странице курса
- Презентации будут доступны по ссылке под каждой лекцией
- Материалы отобразятся списком под каждой лекцией с их названиями
- Аннотации будут видны при раскрытии карточки лекции
