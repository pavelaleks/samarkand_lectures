## 📄 Поддерживаемые форматы файлов {#форматы}

### ✅ Поддерживаемые форматы:

1. **HTML лекции** (`.html`)
   - Текстовый материал лекции
   - Может содержать форматирование, списки, изображения
   - Отображается прямо на странице лекции

2. **PDF презентации** (`.pdf`)
   - Слайды презентации
   - Открываются в новой вкладке при клике

3. **PDF материалы** (`.pdf`)
   - Статьи, книги, дополнительные материалы
   - Отображаются в разделе "Дополнительные материалы"

## ➕ Как добавлять материалы {#добавление}

### Вариант 1: Через PyCharm (рекомендуется)

1. **Откройте проект в PyCharm**
   ```
   File → Open → выберите папку "Site Samarkand"
   ```

2. **Найдите нужный курс в структуре проекта**
   - Например: `src/data/alternative/`

3. **Добавьте файлы:**

   **HTML лекция:**
   - Перейдите в папку `лекции/`
   - Создайте или скопируйте файл с именем `{номер}.html`
   - Пример: `7.html` для лекции №7
   - Если нужно создать JSON для новой лекции: `7.json` с содержимым:
     ```json
     {
       "number": "7",
       "title": "Название лекции"
     }
     ```

   **PDF презентация:**
   - Перейдите в папку `презентации/`
   - Скопируйте файл с именем `{номер}.pdf` или `{номер}_{название}.pdf`
   - Пример: `7.pdf` или `7_Роман-игра.pdf`

   **PDF материалы (статьи, книги):**
   - Перейдите в папку `материалы/`
   - Скопируйте файлы с именами: `{номер}_{название}.pdf`
   - Пример: `7_Статья_о_литературе.pdf`
   - Можно добавить несколько файлов для одной лекции

4. **Сохраните файлы** (Ctrl+S или автоматически)

### Вариант 2: Через Проводник Windows (без PyCharm)

1. **Откройте папку проекта:**
   ```
   C:\Users\PC\PycharmProjects\Site Samarkand
   ```

2. **Перейдите к нужной папке:**
   ```
   src\data\{название_курса}\{тип_материала}\
   ```
   
   Примеры:
   - `src\data\alternative\лекции\` - для HTML
   - `src\data\alternative\презентации\` - для PDF презентаций
   - `src\data\alternative\материалы\` - для PDF статей/книг

3. **Скопируйте файлы** в нужную папку с правильными именами

## 🔄 Как обработать и задеплоить {#деплой}

### Шаг 1: Обработать новые материалы

После добавления файлов запустите скрипт, который найдёт их и добавит в индекс:

**Вариант A: Через PyCharm (Terminal)**
1. Откройте встроенный Terminal в PyCharm (нижняя панель)
2. Выполните команду:
   ```bash
   npm run process-lectures
   ```

**Вариант B: Через PowerShell/CMD**
1. Откройте PowerShell или CMD
2. Перейдите в папку проекта:
   ```powershell
   cd "C:\Users\PC\PycharmProjects\Site Samarkand"
   ```
3. Выполните команду:
   ```bash
   npm run process-lectures
   ```

**Что делает скрипт:**
- Сканирует все папки `лекции/`, `презентации/`, `материалы/`
- Находит новые файлы
- Обновляет файл `src/data/lectures.json`
- Выводит список найденных лекций и материалов

**Ожидаемый вывод:**
```
🔍 Поиск лекций...
  ✓ Найдена презентация: 7.pdf для лекции 7
Найдено 51 лекций
✅ Индекс обновлен. Всего лекций: 51
```

---

### Шаг 2: Проверить изменения (опционально)

Можно проверить, что материалы добавлены правильно:

1. Откройте файл `src/data/lectures.json` в PyCharm
2. Найдите нужную лекцию (по номеру или названию)
3. Проверьте поля:
   - `htmlFile` - путь к HTML файлу (если есть)
   - `presentationPdf` - путь к PDF презентации (если есть)
   - `materials` - массив с материалами (если есть)

---

### Шаг 3: Отправить на GitHub

**Вариант A: Через PyCharm (рекомендуется)**

1. **Посмотрите изменения:**
   - В PyCharm откройте вкладку "Git" (слева) или "Version Control"
   - Или в меню: `VCS → Git → Show Changes`

2. **Добавьте файлы:**
   - В окне "Git" нажмите на файлы правой кнопкой → `Git → Add`
   - Или используйте `Ctrl+Alt+A` (выделите файлы)

3. **Закоммитьте:**
   - Введите сообщение коммита, например:
     ```
     Add materials for lecture 7 (alternative course)
     ```
   - Нажмите `Commit`

4. **Отправить:**
   - `VCS → Git → Push`
   - Или нажмите кнопку `Push` в окне Git

**Вариант B: Через PowerShell/CMD**

1. **Откройте терминал в папке проекта**

2. **Проверьте статус:**
   ```bash
   git status
   ```

3. **Добавьте все изменения:**
   ```bash
   git add src/data/
   ```

4. **Закоммитьте:**
   ```bash
   git commit -m "Add materials for lecture X"
   ```
   (Замените X на номер лекции)

5. **Отправить на GitHub:**
   ```bash
   git push origin main
   ```

---

### Шаг 4: Дождаться деплоя

После отправки на GitHub:

1. **GitHub Actions автоматически запустит деплой**
   - Обычно начинается через 1-2 минуты после push

2. **Проверить статус деплоя:**
   - Откройте: https://github.com/pavelaleks/samarkand_lectures/actions
   - Дождитесь зелёной галочки ✅ (обычно 2-5 минут)

3. **Проверить на сайте:**
   - Откройте: https://pavelaleks.github.io/samarkand_lectures/
   - Найдите нужную лекцию
   - Проверьте, что материалы отображаются

## 🆘 Частые проблемы

**Проблема:** Материалы не появляются после деплоя
- ✅ Проверьте, что запустили `npm run process-lectures`
- ✅ Проверьте, что файлы закоммичены (`git status`)
- ✅ Проверьте название файлов (должно начинаться с номера лекции)

**Проблема:** Файлы не находятся скриптом
- ✅ Проверьте правильность названия папки (`лекции`, `презентации`, `материалы`)
- ✅ Проверьте, что файл начинается с номера лекции (например, `7_название.pdf`)

**Проблема:** Ошибка при `git push`
- ✅ Сначала выполните `git pull` чтобы получить последние изменения
- ✅ Затем снова `git push`
