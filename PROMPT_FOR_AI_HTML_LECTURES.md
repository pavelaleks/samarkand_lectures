# 📝 Инструкция для ИИ: Создание HTML файлов для лекций

Эта инструкция предназначена для ИИ-ассистентов (ChatGPT, Claude, Gemini и др.), которые будут создавать HTML файлы с кратким содержанием лекций для сайта.

---

## 🎯 Задача

Создать HTML файл с кратким содержанием лекции, который будет отображаться на сайте в разделе "Краткое содержание лекции".

---

## 📁 Требования к файлу

### 1. Расположение файла
```
src/data/{course-slug}/лекции/{номер}.html
```

**Где:**
- `{course-slug}` — один из трех вариантов:
  - `alternative` — для курса "Альтернативная литература"
  - `imagology` — для курса "Имагология"
  - `modern-literature` — для курса "Теория и практика современного литературного процесса"

- `{номер}` — номер лекции (например: `1`, `2`, `17`)

**Примеры:**
- `src/data/alternative/лекции/5.html`
- `src/data/imagology/лекции/1.html`
- `src/data/modern-literature/лекции/17.html`

---

### 2. Структура HTML файла

**Важно:** Создавайте только содержимое `<body>`, БЕЗ тегов `<html>`, `<head>`, `<body>`. Сайт автоматически оборачивает контент.

### Минимальная структура:
```html
<h2>Название раздела</h2>
<p>Текст абзаца...</p>

<h2>Другой раздел</h2>
<p>Еще один абзац...</p>
```

### Полная структура (рекомендуется):
```html
<h2>Основные концепции</h2>
<p>Текст абзаца с описанием основных концепций лекции...</p>

<h2>Ключевые темы</h2>
<ul>
  <li>Первая тема</li>
  <li>Вторая тема</li>
  <li>Третья тема</li>
</ul>

<h2>Важные моменты</h2>
<p>Дополнительные важные моменты...</p>

<h2>Заключение</h2>
<p>Краткое резюме...</p>
```

---

## 📋 Требования к содержанию

### Объем
- **Оптимально:** 800-1500 слов
- **Минимум:** 400 слов
- **Максимум:** 2500 слов

### Структура содержания

1. **Введение** (необязательно, можно объединить с основным содержанием)
   - Краткое введение в тему лекции
   - Контекст и актуальность

2. **Основное содержание**
   - Разделение на логические разделы (2-5 разделов)
   - Каждый раздел с заголовком `<h2>`
   - Детальное, но краткое изложение материала

3. **Ключевые концепции** (необязательно)
   - Списки важных понятий
   - Определения ключевых терминов

4. **Заключение** (необязательно)
   - Краткое резюме основных идей
   - Связь с другими лекциями курса

---

## 🎨 Форматирование и стили

### Разрешенные HTML теги

✅ **Можно использовать:**
- `<h2>`, `<h3>`, `<h4>` — заголовки
- `<p>` — параграфы
- `<ul>`, `<ol>`, `<li>` — списки
- `<strong>`, `<em>` — выделение текста
- `<blockquote>` — цитаты
- `<a href="...">` — ссылки (если нужны)
- `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>` — таблицы
- `<img src="..." alt="...">` — изображения (если нужны)

❌ **Не использовать:**
- `<div>`, `<span>` — используются только для специальных случаев
- `<style>`, `<script>` — стили и скрипты
- `<html>`, `<head>`, `<body>` — эти теги добавляет сайт

---

### Рекомендации по форматированию

1. **Заголовки:**
   ```html
   <h2>Основные концепции</h2>
   <h3>Подраздел (если нужен)</h3>
   ```

2. **Абзацы:**
   ```html
   <p>Текст параграфа с детальным описанием...</p>
   ```

3. **Списки:**
   ```html
   <ul>
     <li>Первый пункт</li>
     <li>Второй пункт</li>
     <li>Третий пункт</li>
   </ul>
   ```

4. **Выделение важного:**
   ```html
   <p>Важное понятие <strong>термин</strong> требует особого внимания...</p>
   <p>Это <em>подчеркивает</em> акцент на определенной идее...</p>
   ```

5. **Цитаты (если есть):**
   ```html
   <blockquote>
     <p>Важная цитата из источника...</p>
   </blockquote>
   ```

## 📝 Пример готового HTML файла

```html
<h2>Альтернативная литература как понятие</h2>

<p>Альтернативная литература представляет собой совокупность текстовых практик, которые существуют <strong>вне канона</strong>, формируя собственные художественные традиции и читательские сообщества. Это понятие включает в себя три основных концепта: «вне канона», «контркультура» и «нон-мейнстрим».</p>

<h2>Три основных подхода к определению</h2>

<h3>«Вне канона»</h3>
<p>Литературные тексты, которые сознательно или объективно исключены из официального канона по различным причинам: идеологическим, эстетическим, коммерческим или институциональным.</p>

<h3>«Контркультура»</h3>
<p>Литературные практики, которые сознательно противопоставляют себя доминирующей культуре, создавая альтернативные системы ценностей, эстетики и социальных отношений.</p>

<h3>«Нон-мейнстрим»</h3>
<p>Тексты, которые не вписываются в коммерческий мейнстрим, но при этом не обязательно являются контркультурными. Сюда относятся нишевые жанры, экспериментальные формы, региональная литература.</p>

<h2>Механизмы исключения и включения</h2>

<p>Канон формируется через сложные механизмы:</p>
<ul>
  <li><strong>Институциональные:</strong> издательства, премии, университетские программы</li>
  <li><strong>Критические:</strong> рецензии, литературная критика, академические исследования</li>
  <li><strong>Коммерческие:</strong> маркетинг, продажи, популярность</li>
  <li><strong>Идеологические:</strong> соответствие доминирующим ценностям</li>
</ul>

<h2>Значение для литературоведения</h2>

<p>Изучение альтернативной литературы позволяет понять динамику литературного процесса, механизмы формирования канона и роль маргинальных практик в развитии литературы. Это исследовательское поле открывает доступ к текстам, которые традиционно оставались вне внимания академического литературоведения.</p>
```

## ✅ Чеклист перед сохранением файла

- [ ] Файл назван правильно: `{номер}.html` (например: `5.html`)
- [ ] Файл сохранен в правильной папке: `src/data/{course-slug}/лекции/`
- [ ] Содержит только контент БЕЗ тегов `<html>`, `<head>`, `<body>`
- [ ] Использует правильную структуру с заголовками `<h2>`, `<h3>`
- [ ] Текст читаемый, структурированный, логически организован
- [ ] Объем соответствует требованиям (800-1500 слов оптимально)
- [ ] Нет ошибок в разметке HTML (можно проверить валидатором)
- [ ] Кириллица корректно отображается (UTF-8 кодировка)

## 💡 Советы для создания качественного контента

1. **Адаптивность:**
   - Контент будет читаться на мобильных устройствах
   - Используй короткие абзацы (3-5 предложений)
   - Не делай слишком длинные списки (5-7 пунктов максимум)

2. **Читаемость:**
   - Разбивай длинные тексты на логические блоки
   - Используй заголовки для навигации
   - Добавляй пустые строки между разделами

3. **Академический стиль:**
   - Используй точную терминологию
   - Приводи конкретные примеры и концепции
   - Сохраняй баланс между детальностью и краткостью

4. **Структура:**
   - Начинай с общего контекста
   - Переходи к конкретным концепциям
   - Заканчивай выводами или связью с другими темами

---

## 📌 Важные напоминания

⚠️ **НЕ используй:**
- JavaScript (`<script>`)
- Встроенные стили (`<style>`, атрибут `style`)
- Сложные CSS классы
- Внешние зависимости

✅ **ИСПОЛЬЗУЙ:**
- Семантическую HTML разметку
- Стандартные теги для структуры
- Простое и понятное форматирование

---

## 🔍 Проверка файла

После создания файла проверь:

1. Открой файл в браузере — должен корректно отображаться
2. Проверь кодировку — кириллица должна читаться
3. Проверь структуру — все теги закрыты, нет ошибок
4. Проверь объем — соответствует требованиям

---

## 📞 Что делать после создания

После того, как ИИ создал HTML файл:

1. Сохрани файл в правильную папку
2. Проверь содержимое
3. При необходимости отредактируй
4. Запусти `npm run process-lectures` чтобы обновить индекс
5. Закоммить изменения (см. `HOW_TO_COMMIT.md`)
