# Промпт для создания HTML файлов лекций

## Задача

Создай HTML файл для лекции по литературоведению. Файл будет использоваться на академическом сайте с адаптивным дизайном (desktop и mobile).

---

## Технические характеристики файла

### Формат и сохранение
- **Формат файла**: `.html`
- **Кодировка**: UTF-8
- **Название файла**: `[номер].html` (например: `1.html`, `2.html`, `10.html`)
- **Размер**: Оптимизированный, без лишних пробелов в критических местах
- **Структура**: Можно использовать полный HTML документ ИЛИ только содержимое body (без `<html>`, `<head>`, `<body>` тегов)

### Рекомендуемый формат (только содержимое)
```html
<h2>Название раздела лекции</h2>
<p>Текст параграфа...</p>
<p>Еще один параграф...</p>
```

---

## Структура и разметка HTML

### Основные требования к разметке

1. **Семантические HTML5 теги**:
   - Используй `<h2>` для основных разделов лекции
   - Используй `<h3>` для подразделов
   - Используй `<p>` для параграфов
   - Используй `<ul>` / `<ol>` для списков
   - Используй `<strong>` для важных терминов
   - Используй `<em>` для акцентов

2. **Не используй**:
   - ❌ `<h1>` (заголовок лекции уже есть на странице)
   - ❌ `<style>` теги (стили применяются автоматически)
   - ❌ `<script>` теги
   - ❌ Встроенные стили через `style=""`
   - ❌ Классы CSS (применяются автоматически)
   - ❌ Полные пути к ресурсам

3. **Форматирование текста**:
   ```html
   <p>Обычный текст параграфа с <strong>важными терминами</strong> и <em>акцентами</em>.</p>
   ```

4. **Списки**:
   ```html
   <ul>
     <li>Первый пункт списка</li>
     <li>Второй пункт списка</li>
   </ul>
   
   <ol>
     <li>Пронумерованный пункт 1</li>
     <li>Пронумерованный пункт 2</li>
   </ol>
   ```

5. **Цитаты**:
   ```html
   <blockquote>
     <p>Цитируемый текст с сохранением форматирования.</p>
   </blockquote>
   ```

6. **Ссылки** (если нужны):
   ```html
   <p>Текст со <a href="https://example.com">ссылкой</a> на источник.</p>
   ```

## Организация материала лекции

### Структура содержимого

1. **Введение** (необязательно, если не нужно):
   ```html
   <h2>Введение</h2>
   <p>Краткое вступление к теме лекции...</p>
   ```

2. **Основные разделы** (2-5 разделов):
   ```html
   <h2>Название раздела</h2>
   <p>Текст раздела...</p>
   
   <h3>Подраздел</h3>
   <p>Текст подраздела...</p>
   ```

3. **Примеры и иллюстрации**:
   ```html
   <h2>Примеры</h2>
   <p>Рассмотрим пример:</p>
   <ul>
     <li>Пример 1: описание</li>
     <li>Пример 2: описание</li>
   </ul>
   ```

4. **Заключение** (необязательно):
   ```html
   <h2>Заключение</h2>
   <p>Выводы и обобщения...</p>
   ```

### Рекомендации по организации

- **Длина параграфов**: 3-7 предложений для лучшей читаемости
- **Разделение текста**: Используй `<h2>` для визуального разделения крупных блоков
- **Списки**: Используй для перечислений, ключевых моментов, примеров
- **Акценты**: Выделяй важные термины через `<strong>`
- **Примеры**: Выделяй примеры отдельными разделами или списками

---

## Оптимизация для чтения

### Для мобильных устройств

1. **Короткие параграфы**: 3-5 предложений максимум
2. **Ясная структура**: Используй заголовки `<h2>` для визуального разделения
3. **Списки вместо длинных абзацев**: Когда возможно, используй `<ul>` / `<ol>`
4. **Избегай длинных предложений**: Разбивай сложные конструкции

### Для десктопа

1. **Сбалансированная длина**: Параграфы могут быть немного длиннее (5-7 предложений)
2. **Детализация**: Можно включать больше примеров и пояснений
3. **Структурированность**: Четкая иерархия заголовков

## Примеры правильной разметки

### Пример 1: Простая лекция с разделами
```html
<h2>Введение в тему</h2>
<p>Лекция посвящена изучению <strong>альтернативной литературы</strong> как феномена современной культуры.</p>

<h2>Основные понятия</h2>
<p>Альтернативная литература определяется через три ключевые оси:</p>
<ul>
  <li><strong>Вне канона</strong> — тексты, исключенные из институционального признания</li>
  <li><strong>Контркультура</strong> — литература, сознательно противостоящая мейнстриму</li>
  <li><strong>Нон-мейнстрим</strong> — практики, существующие параллельно массовой индустрии</li>
</ul>

<h2>Исторические примеры</h2>
<p>Классическим примером альтернативной литературы является <em>самиздат</em> в СССР. Самиздат представлял собой систему неофициального распространения текстов, запрещенных государственной цензурой.</p>

<h3>Битники в США</h3>
<p>Движение битников (1950-е годы) также можно рассматривать как пример альтернативной литературы. Произведения <strong>Джека Керуака</strong> и <strong>Аллена Гинзберга</strong> сознательно противопоставляли себя мейнстриму.</p>
```

### Пример 2: Лекция с примерами и цитатами
```html
<h2>Теоретические основы</h2>
<p>Концепция альтернативной литературы развивалась в работах Пьера Бурдьё, который рассматривал литературное поле как пространство борьбы за легитимность.</p>

<blockquote>
  <p>Литературное поле представляет собой структурированное пространство позиций, в котором происходит борьба за установление границ легитимности.</p>
</blockquote>

<h2>Современные формы</h2>
<p>В XXI веке альтернативная литература включает:</p>
<ol>
  <li>Фанфикшн — творчество читателей на основе существующих произведений</li>
  <li>Цифровая поэзия — произведения, созданные специально для цифровой среды</li>
  <li>AI-тексты — произведения, созданные с помощью искусственного интеллекта</li>
</ol>

<h3>Фанфикшн как феномен</h3>
<p>Фанфикшн представляет собой уникальный пример <strong>вторичной литературы</strong>, где читатель становится соавтором. Это явление демонстрирует, как альтернативные практики могут влиять на канонические тексты.</p>
```

## Чек-лист перед сохранением файла

- [ ] Файл сохранен как `[номер].html` (UTF-8)
- [ ] Использованы только семантические HTML5 теги
- [ ] Нет встроенных стилей и классов
- [ ] Нет `<h1>` тегов (только `<h2>`, `<h3>`)
- [ ] Параграфы структурированы логично
- [ ] Длинные тексты разбиты на разделы
- [ ] Важные термины выделены через `<strong>`
- [ ] Списки используются для перечислений
- [ ] Текст оптимизирован для мобильного чтения
- [ ] Проверена читаемость на экранах разного размера

---

## Дополнительные рекомендации

1. **Академический стиль**: Сохраняй научный, но доступный язык
2. **Структурированность**: Логичная последовательность разделов
3. **Визуальная иерархия**: Используй заголовки для создания ясной структуры
4. **Читаемость**: Разбивай длинные блоки текста на короткие параграфы
5. **Примеры**: Включай конкретные примеры для иллюстрации теории

## Контекст использования

Файл будет встроен в React-компонент с автоматическим применением стилей Tailwind CSS:
- Адаптивная типографика (clamp для размеров шрифта)
- Темная/светлая тема
- Оптимизация для touch-устройств
- Автоматическое форматирование через Tailwind Typography

**Важно**: Просто создавай чистый семантический HTML — стили применятся автоматически!
