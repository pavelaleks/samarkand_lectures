Создай HTML файл для академической лекции по литературоведению.

ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ:
- Формат: чистый HTML без тегов <html>, <head>, <body>, <style>, <script>
- Кодировка: UTF-8
- Сохрани как: только содержимое (можно начать с <h2>)
- Название файла: [номер].html (например: 1.html, 2.html)

СТРУКТУРА РАЗМЕТКИ:
- Используй семантические HTML5 теги: <h2> для разделов, <h3> для подразделов, <p> для параграфов, <ul>/<ol> для списков
- НЕ используй: <h1>, встроенные стили, классы CSS, теги <style> или <script>
- Выделяй важные термины через <strong>, акценты через <em>
- Цитаты оформляй через <blockquote>

ОРГАНИЗАЦИЯ МАТЕРИАЛА:
- Раздели лекцию на 2-5 основных разделов через <h2>
- Каждый раздел содержит параграфы <p> (3-7 предложений)
- Используй списки <ul>/<ol> для перечислений и примеров
- Длинные блоки текста разбивай на короткие параграфы

ОПТИМИЗАЦИЯ ДЛЯ ЧТТЕНИЯ:
- Параграфы: 3-5 предложений для мобильных, 5-7 для десктопа
- Структура: используй <h2> для визуального разделения блоков
- Списки: предпочитай списки длинным абзацам с перечислениями
- Избегай длинных сложных предложений

ПРИМЕР РАЗМЕТКИ:
<h2>Название раздела</h2>
<p>Текст параграфа с <strong>важными терминами</strong> и <em>акцентами</em>.</p>

<h3>Подраздел</h3>
<p>Еще один параграф...</p>

<ul>
  <li>Пункт списка 1</li>
  <li>Пункт списка 2</li>
</ul>

ЧЕКЛИСТ:
- Только семантические HTML теги
- Нет встроенных стилей
- Логичная структура разделов
- Параграфы оптимизированы для чтения
- Важные термины выделены <strong>

Файл будет автоматически стилизован через Tailwind CSS с адаптивным дизайном. Просто создавай чистый семантический HTML!
