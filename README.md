# Samarkand Lectures

**Курсы профессора Павла Алексеева — Самаркандский государственный университет им. Шарофа Шафирова**

Современный веб-сайт для трех курсов лекций по литературоведению с поддержкой интерактивных материалов, тестов и автоматической генерации аннотаций.

## 🎯 Особенности

- 🌐 Двуязычный интерфейс (Русский/Английский)
- 🌓 Темная/светлая тема
- 📚 3 курса, 51 лекция
- 🧪 Интерактивные тесты
- 🤖 Автоматическая генерация аннотаций через DeepSeek API
- 📱 Адаптивный дизайн
- ✨ Плавные анимации (Framer Motion)

## 🚀 Быстрый старт

### Установка

```bash
npm install
```

### Разработка

```bash
npm run dev
```

### Сборка

```bash
npm run build
```

### Обработка лекций

```bash
npm run process-lectures
```

## 📁 Структура проекта

```
src/
├── components/     # React компоненты
├── pages/          # Страницы сайта
├── contexts/       # React контексты (тема, язык)
├── data/           # Данные: курсы, лекции, тесты
└── utils/          # Утилиты (DeepSeek API, markdown)
```

## 🔧 Настройка DeepSeek API

1. Скопируйте `.env.example` в `.env`
2. Добавьте ваш API ключ DeepSeek:
   ```
   VITE_DEEPSEEK_API_KEY=your-key-here
   ```

## 📝 Добавление новых лекций

### Структура папок для каждого курса:
```
src/data/[course-slug]/
├── лекции/          # .docx, .doc или .md файлы (пронумерованы: 1.docx, 2.docx...)
├── презентации/     # PDF презентации (пронумерованы: 1.pdf, 2.pdf...)
└── материалы/       # PDF материалы к лекциям (названия будут использованы как есть)
```

### Процесс добавления:

1. **Лекции**: Поместите файлы лекций (`.docx`, `.doc` или `.md`) в папку `лекции/`, назвав их по номеру: `1.docx`, `2.docx`, `3.docx` и т.д.

2. **Презентации**: Поместите PDF презентации в папку `презентации/` с теми же номерами: `1.pdf`, `2.pdf`, `3.pdf` и т.д.

3. **Материалы**: Поместите PDF материалы в папку `материалы/`. Названия могут начинаться с номера лекции, например: `1 - Название материала.pdf`. Название после номера будет использовано для отображения.

4. **Обработка**: Запустите скрипт для обновления индекса:
   ```bash
   npm run process-lectures
   ```

5. **Генерация аннотаций**: Используйте админ-панель (`/admin`) для генерации расширенных аннотаций через DeepSeek API
