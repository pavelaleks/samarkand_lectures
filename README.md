# Samarkand Lectures

**Курсы профессора Павла Алексеева — Самаркандский государственный университет им. Шарофа Рашидова**

Современный веб-сайт для курсов лекций с презентациями, материалами и интерактивным демо-стендом.

## Особенности

- Двуязычный интерфейс (Русский/Английский)
- Тёмная/светлая тема
- Интерактивные презентации и PDF
- Материалы для каждой лекции
- Адаптивный дизайн

## Демо-стенд (курс Digital Humanities)

Раздел живого показа методов на лекции: `/courses/digital-humanities/demo`

- Каталог и сценарии: `src/data/demos.json`
- Страницы: `src/pages/LabHub.jsx`, `src/pages/LabWork.jsx` (оболочка презентера)
- Инструменты: `src/lab/tools/`
- Старые ссылки `/lab`… автоматически ведут на `/demo`…

Это не канал сдачи работ: задания для практики даются отдельно. На лекции — вопрос → клик/пресет → эффект → лимит метода.

Плейлист сценариев для преподавателя: `DEMO_LECTURE_PLAYBOOK.md`

### Установка

```bash
npm install
```

### Разработка

```bash
npm run dev
```

### Сборка

```bash
npm run build
```

## Добавление лекций

Для каждой лекции создайте JSON файл в папке `src/data/[курс]/лекции/`.

### Добавление PDF материалов

1. Поместите PDF файлы в `src/data/[курс]/материалы/`
2. Назовите файлы с номером лекции: `1_название_статьи.pdf`
3. Запустите: `npm run process-lectures`
