# Samarkand Lectures

**Курсы профессора Павла Алексеева — Самаркандский государственный университет им. Шарофа Шафирова**

Современный веб-сайт для трех курсов лекций по литературоведению с поддержкой интерактивных материалов, тестов и автоматической генерации аннотаций.

## 🎯 Особенности

- 🌐 Двуязычный интерфейс (Русский/Английский)
- 🌓 Темная/светлая тема
- 📚 3 курса, 51 лекция
- 🧪 Интерактивные тесты
- 🤖 Автоматическая генерация аннотаций через DeepSeek API
- 📱 Адаптивный дизайн
- ✨ Плавные анимации (Framer Motion)

## 🚀 Быстрый старт

### Установка

```bash
npm install
```

### Разработка

```bash
npm run dev
```

### Сборка

```bash
npm run build
```

### Обработка лекций

```bash
npm run process-lectures
```

## 📁 Структура проекта

```
src/
├── components/     # React компоненты
├── pages/          # Страницы сайта
├── contexts/       # React контексты (тема, язык)
├── data/           # Данные: курсы, лекции, тесты
└── utils/          # Утилиты (DeepSeek API, markdown)
```

## 🔧 Настройка DeepSeek API

1. Скопируйте `.env.example` в `.env`
2. Добавьте ваш API ключ DeepSeek:
   ```
   VITE_DEEPSEEK_API_KEY=your-key-here
   ```

## 📝 Добавление новых лекций

1. Поместите `.md` файл в соответствующую папку: `src/data/[course-slug]/[number].md`
2. Запустите скрипт обработки:
   ```bash
   npm run process-lectures
   ```
3. Используйте админ-панель (`/admin`) для генерации аннотаций

## 🚀 Деплой на GitHub Pages

Проект настроен для деплоя на GitHub Pages. После push в `main` ветку, проект автоматически соберется и будет доступен по адресу:

`https://pavelaleks.github.io/samarkand_lectures/`
