# Samarkand Lectures

**Курсы профессора Павла Алексеева — Самаркандский государственный университет им. Шарофа Шафирова**

Современный веб-сайт для трех курсов лекций с интерактивными Gamma-презентациями и материалами для чтения.

## 🎯 Особенности

- 🌐 Двуязычный интерфейс (Русский/Английский)
- 🌓 Темная/светлая тема
- 📊 Интерактивные Gamma-презентации
- 📚 PDF материалы для каждой лекции
- 📱 Адаптивный дизайн для мобильных устройств
- ✨ Современный UI/UX с плавными анимациями

## 📝 Добавление лекций

### Структура

Для каждой лекции создайте JSON файл в папке `src/data/[курс]/лекции/`:

**Пример: `src/data/alternative/лекции/1.json`**

```json
{
  "number": "1",
  "title": "Альтернативная литература как понятие: «вне канона», «контркультура», «нон-мейнстрим».",
  "gammaUrl": "https://gamma.app/embed/iti4sjrsnaqw48i",
  "id": "alternative-1"
}
```

### Добавление PDF материалов

1. Поместите PDF файлы в `src/data/[курс]/материалы/`
2. Назовите файлы с номером лекции: `1_название_статьи.pdf`
3. Запустите: `npm run process-lectures`
