Сюда run_pipeline.py складывает результаты:

  raw/      — сырые ответы модели (JSON), по файлу на фрагмент. Не удаляйте: без них прогон не воспроизвести.
  tables/   — results.csv (последний прогон) и results_<промпт>_<дата>.csv (история)
  errors/   — битый JSON и HTTP-ошибки. Их не «чинят молча»: смотрят и правят промпт.
